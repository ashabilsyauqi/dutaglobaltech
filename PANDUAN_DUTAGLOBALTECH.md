## 🚀 Cara Menjalankan Website

### Cara Paling Mudah:
Cukup **klik 2x (double-click)** file `Buka_Web_DutaGlobalTech.bat` di folder ini. Server lokal akan aktif dan browser otomatis membuka websitenya.

### Cara Manual via Terminal:
```bash
# 1. Jalankan development server
npm run dev

# 2. Buka di browser
http://localhost:3000

# 3. Build untuk rilis produksi (tersimpan di folder dist/)
npm run build
```
